# Coding Samples

Selected code samples from my graduate research and research assistant work in economics. Each project has its own folder and README. Where a project is a shortened version, its README links to the full version in its own repository.

## Projects

| Project | Software | Description |
|---|---|---|
| [`census-mother-child-linkage`](census-mother-child-linkage/) | Stata | Identifies mothers and links them to their children within households in historical US full-count census data (IPUMS), for a research project on historical nonmarital fertility. |
| [`boc-impulse-responses`](boc-impulse-responses/) | R | Local projection impulse responses of CPI, real GDP and unemployment to an interest rate shock, from the Bank of Canada Governor's Challenge. Full version: [Bank-of-Canada-Governor-s-Challenge-](https://github.com/khushishah-18/Bank-of-Canada-Governor-s-Challenge-). |
| [`scm-cannabis-productivity`](scm-cannabis-productivity/) | Python | Synthetic control analysis of the effect of Canada's 2018 cannabis legalization on labour productivity, with placebo inference. Full version: [ECON-526---Roa-a-Khushi](https://github.com/khushishah-18/ECON-526---Roa-a-Khushi). |

## Notes

- Some projects use restricted-access or large datasets that are not included, so those samples are shared to show the code and how it is organized rather than to be run as-is. Each project's README says what is needed to run it.
